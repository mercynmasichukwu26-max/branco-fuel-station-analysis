
# Branco Fuel Station: Performance Analysis 2025

 Project Overview
Analysed 31,895 fuel transactions from Branco Fuel Station covering 
January to December 2025. The goal was to identify revenue trends, 
top performing months, best attendants, fuel type breakdown and 
business insights to support decision making.

Tools Used
- Microsoft Excel: Pivot Tables, Charts, Interactive Dashboard, Slicers
- MySQL Workbench: Data querying and analysis
- Power BI: Data visualisation

 Key Insights
- Total Annual Revenue: ₦1,723,002,149
- Best Performing Month: December 2025 (₦229.8M)
- Best Performing Quarter: Q4
- Top Fuel Type: PMS (59% of total revenue)
- Top Attendant: Kemi (₦293.4M)
- Weekdays generate 71.7% of total revenue vs 28.3% weekends

Files
- Branco_Fuel_Station_2025.xlsx: Excel dashboard with charts and slicers
- Branco_Fuel_Project.sql: 20 SQL queries answering business questions
- Branco_Fuel_Station_2025.sql: Database setup and table structure

Skills Demonstrated
- Data cleaning and preparation
- Pivot tables and interactive dashboards
- SQL querying with GROUP BY, SUM, COUNT, CASE statements
- Business insight generation from raw data
